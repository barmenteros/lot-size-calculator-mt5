# Lot Size Calculator for MetaTrader 5

Free MT5 indicator. Enter your risk as a percentage of your account, drag the stop-loss line to
your level, and the panel shows the lot size, rounded to a volume your broker accepts.

## Download

**[Download the latest version](https://github.com/barmenteros/lot-size-calculator-mt5/releases/latest/download/Lot-Size-Calculator-MT5.zip)**

Earlier versions and what changed in each: [Releases](https://github.com/barmenteros/lot-size-calculator-mt5/releases).

## Install

1. Unzip the downloaded file.
2. In MetaTrader 5, open **File > Open Data Folder**, then the folder **MQL5 > Indicators**.
3. Copy `Lot Size Calculator.ex5` into that folder.
4. Restart MetaTrader 5, or right-click **Indicators** in the Navigator and choose **Refresh**.
5. Drag **Lot Size Calculator** from the Navigator onto a chart.

The panel's title shows the version you are running.
